Organization-level GitHub configuration for [LethalModding](https://github.com/LethalModding). Houses the public org profile README and shared repository metadata for this special `.github` repository.

## Quick start

```bash
git clone https://github.com/LethalModding/.github.git
```

This org-templates dossier has no HUMANS-tier runbook — edit `profile/README.md` for the landing page shown on github.com/LethalModding.
