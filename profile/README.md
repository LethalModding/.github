# LethalModding

Game modding projects and tooling.

## Mod manager

[Concrete](https://github.com/LethalModding/Concrete), our Lethal Company mod
manager, is archived. Its successor is
[Mortar](https://github.com/Rethunk-Tech/mortar)
([mortar.rethunk.tech](https://mortar.rethunk.tech/)), a desktop mod manager
for several games. Mortar supports Stardew Valley today; Lethal Company
support is planned for a later release.
